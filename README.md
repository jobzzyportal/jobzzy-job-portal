# Jobzzy Job Portal

Jobzzy is a MERN stack job application portal where recruiters can post jobs and candidates can apply for them.

This project demonstrates Agile and DevOps practices including:

- Scrum-based development
- Version control using GitHub
- Containerization using Docker
- CI/CD using GitHub Actions
- Deployment using Vercel and Render

Tech Stack:
- MongoDB
- Express.js
- React.js
- Node.js
